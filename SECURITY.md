# Security policy

Report a suspected vulnerability in omada-inside using [GitHub's private vulnerability reporting form](https://github.com/wolfgangkiefer1006/omada-inside/security/advisories/new). Please keep the report private while it is being reviewed.

Include the affected omada-inside version or container image tag, the relevant configuration without secrets, and a short description of the observed behavior and its impact. Redact passwords, API tokens, encryption keys, and private network details from logs or screenshots before attaching them.
